# 转盘 × 红包活动作品集

这是一个可运行的 Next.js 活动前端作品集，包含：

- `/spin`：转盘抽奖、探宝券、奖品记录与领取流程
- `/red-envelope-video`：代币红包发送流程
- `/red-envelope-home`、`/red-envelope-motion`：红包相关展示与动效页面

## 本地运行

```bash
npm install
npm run dev
```

## 项目资料

- `docs/`：转盘 PRD 与项目归档
- `project-data/`：红包项目规格、图层清单与 QA 产出
- `deliveries/`：红包页面交付源码与可复用产出
- `public/assets/`：转盘和红包运行所需设计图
